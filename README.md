# FitPrint 🏋️‍♂️

FitPrint is an all-in-one health tracker designed to help you leave your mark on your fitness journey. With a focus on rich aesthetics and a high-performance user experience, FitPrint combines workout tracking, sleep logging and body metrics into a single, cohesive ecosystem.

## ✨ Features

### 🏋️ Gym & Strength Training
*   **Routine Management:** Create and customize workout routines for quick-start training.
*   **Exercise Library:** Access an extensive library of exercises with detailed instructions and animated GIF demonstrations (powered by ExerciseDB).
*   **Session Tracking:** Real-time tracking of sets, reps, and weights.
*   **Muscle Targeting:** Smart categorization of exercises by muscle groups and body parts.

### 🏃 Run Tracking
*   **Activity Logs:** Log your runs manually or synchronize with external platforms.
*   **OCR Integration:** Innovative workout import feature using on-device text recognition (Google ML Kit) to extract data from screenshots.
*   **Performance Metrics:** Automatic calculation of pace, distance, and duration with visual progress indicators.

### 📊 Body Metrics & Analytics
*   **Comprehensive Tracking:** Log weight, body fat percentage, BMI, bone mass, visceral fat, and more.
*   **Chart Visualizations:** Beautiful, interactive charts to visualize your physical transformation over time.
*   **Health Insights:** Automatic BMI categorization and target goal monitoring.

### 😴 Sleep Tracking
*   **Comprehensive Tracking:** Log sleep duration, quality, and wake-up times.
*   **Chart Visualizations:** Beautiful, interactive charts to visualize your sleep patterns over time.
*   **Health Insights:** Automatic sleep quality categorization and target goal monitoring.

### 🔔 Notifications
*   **Smart Reminders:** Get notified when it's time to sleep or wake up.
*   **Activity Reminders:** Get notified when it's time to work out.

### 🏆 Achievements
*   **Track your progress:** Earn badges for hitting milestones in your fitness journey.
*   **Stay motivated:** Unlock achievements to keep pushing yourself.

## 🎨 Design Philosophy

FitPrint features a **Simple Aesthetic** designed for high visibility in gym environments:
*   **Vibrant UI:** Simple gradients to maximize visibility.
*   **Micro-Animations:** Smooth transitions and feedback loops enhance user interaction.
*   **Dynamic Theming:** Native support for Dark and Light modes.

## 🛠 Tech Stack

*   **Framework:** [Flutter](https://flutter.dev) (The UI Toolkit from Google)
*   **State Management:** [Provider](https://pub.dev/packages/provider) for reactive data flows.
*   **Local Persistence:** [Hive CE](https://pub.dev/packages/hive_ce) for ultra-fast, local-first data storage.
*   **Health Tech:** [Google ML Kit](https://developers.google.com/ml-kit) for on-device OCR workout imports.
*   **Visuals:** [FL Chart](https://pub.dev/packages/fl_chart) for premium data visualization and [Cached Network Image](https://pub.dev/packages/cached_network_image) for lightning-fast media loading.
*   **Notifications:** [Flutter Local Notifications](https://pub.dev/packages/flutter_local_notifications) for scheduling notifications.
